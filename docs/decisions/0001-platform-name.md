# ADR 0001: Platform Name

## Status

Accepted

## Decision

The platform is named LearnStack.

## Context

The product is a core platform for building education products. The name should suggest both learning and a reusable technical foundation.

## Consequences

- Repository and directory names should use `learnstack`.
- Product-facing documentation should use `LearnStack`.
- Project and namespace names should use `LearnStack`.
