# Phase 02b exit evidence index

This index preserves source order for all 26 top-level Deliverables, 60 Completion
Criteria and 11 Phase Exit Decision obligations in [Phase 02b](phase-02b-events-auth.md).
The abbreviated locators below do not replace, weaken or omit the canonical bullet's
subordinate conditions. Each row refers to its entire canonical bullet.

This is an ownership index. The
[P02b-8 Step 4 closeout](phase-02b-delivery-log.md#p02b-8-step-4--completed-source-qualification-and-review-closeout-2026-10-25)
records completed exact-source A/B, artifact/skip/cleanup evidence and the dated
live required-check read-back. The review PR's live checks own qualification of
its actual current head. The frozen-source receipt does not imply a passing
result for a later documentation-only commit; maintainer review and merge remain
separate gates.

Evidence lanes: **B** = backend base/unit/architecture and non-Docker HTTP tests;
**I** = real Docker/PostgreSQL/Keycloak/native-HTTPS integration; **F** = frontend
Vitest/source/boundary behavior; **J** = stopped-provider public browser and 27
Lighthouse audits; **O** = generated OpenAPI/SDK and required diff check;
**M** = source/governance/manual census and offline `meta` controls. The executed
case and trait census assigns real Docker/native work to I and base HTTP work to
B, including tests in the `LearnStack.Tests.Integration` assembly.

Backend class names resolve in the Unit, Architecture or Integration project
under `backend/tests/`. A partial filename is identified separately from its
declaring test class.
Integration database classes live in `Database/`; provider/native classes live in
`TenancyIdentity/`. Frontend paths are relative to `frontend/apps/web/` unless an
SDK or repository-root path is shown. A filename without a directory identifies
the matching source under that root. Each row names the proof owner for its
particular assertion. Execution evidence remains the responsibility of that
owner's required lane and the Step 4 record.
