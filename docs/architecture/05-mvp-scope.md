# MVP Scope

The MVP should prove that LearnStack can create and operate one real education platform without hardcoding that platform into the core.

## MVP Goal

Create a tenant-aware education CMS and learning catalog foundation that can later power an online English education platform.

## Included

### Platform Administration

- Create and manage tenants.
- Configure tenant branding basics.
- Configure custom domain metadata.
- Manage feature flags.

### Identity

- Admin login.
- User management.
- Role and permission basics.
- Tenant membership.
- Invitations.

### CMS

- Content types.
- Content entries.
- Pages.
- Page blocks.
- Draft and published versions.
- Navigation menus.

### Media

- Upload files to MinIO.
- Store asset metadata.
- Use images/documents inside content and pages.

### Education Catalog

- Programs.
- Courses.
- Course versions.
- Modules.
- Lessons.
- Categories, levels, and tags.

### Enrollment Basics

- Assign learner access to courses.
- Track simple lesson progress.

### Public Rendering

- Render tenant landing pages.
- Render course catalog.
- Render course detail page.

### Admin Studio

- Manage pages, content, media, and courses.
- Preview published public pages.

## Deferred

- Full payment flow.
- Full subscription lifecycle.
- Advanced assessment engine.
- Native video conferencing.
- Mobile apps.
- Complex reporting dashboards.
- LTI/xAPI implementation.
- Marketplace features.

## First Vertical Product Candidate

Online English education can be the first proving ground.

Early product-specific extensions:

- CEFR levels.
- Placement test.
- Teacher profile fields.
- Lesson package metadata.
- Speaking practice content type.
- Vocabulary list content type.
